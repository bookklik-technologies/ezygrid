Try it yourself

  1. Edit a revenue value in column B. Column D calculates profit.
  2. Select B5 to see =SUM(B2:B4) in the formula bar.
  3. Select B7. Its target comes from =Targets!B2, in the workbook's second sheet.

Double-click or press F2 to edit. Press Enter to commit and Escape to cancel.

See the setup 
<div id="editor" style="height: 460px"></div>
<script src="/ezygrid/ezygrid.js"></script>
<script>
  Ezygrid.ready.then(() => {
    const editor = new Ezygrid({
      target: '#editor',
      worksheets: [{
        name: 'Sales',
        data: [['Revenue', 'Cost', 'Profit'], [12000, 7000, '=A2-B2']],
      }],
    });
    editor.workbook.activeWorksheet.setValue(1, 0, 15000);
  }).catch(console.error);
</script>
