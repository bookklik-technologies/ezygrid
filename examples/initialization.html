Try it yourself

  1. Type something into the empty editor. It was created automatically from data-ezg-editor.
  2. In the order sheet, change the quantity in B2. Its total in D2 recalculates.
  3. Rescan the page. The first editor keeps its content.

Each host needs an explicit height. Wait for Ezygrid.ready before using the JavaScript API.

See the setup 
<div data-ezg-editor style="height: 310px"></div>
<div id="editor" style="height: 310px"></div>
<script src="/ezygrid/ezygrid.js"></script>
<script>
  Ezygrid.ready.then(() => {
    const editor = new Ezygrid({
      target: '#editor',
      worksheets: [{ data: [['Quantity', 'Price', 'Total'], [2, 12, '=A2*B2']] }],
    });
  }).catch(console.error);
</script>
