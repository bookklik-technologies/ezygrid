At home in React.

Use the first-party Spreadsheet component with workbook data, renderer options, and an onReady callback.

Try it yourself

  1. Edit the actual spend in column C. Variance is budget minus actual.
  2. Select a formula cell to inspect it in the formula bar.
  3. The component owns the renderer lifecycle; your workbook owns cell edits.

This framework demo retains its React build. The other examples use ordinary script tags.

See the React setup 
import { Spreadsheet } from '@ezygrid/react';

<Spreadsheet
  worksheets={[{ data: [['Budget', 'Actual', 'Variance'], [100000, 92000, '=A2-B2']] }]}
  renderer={{ toolbar: true, formulaBar: true }}
  style={{ height: 480 }}
  onReady={(workbook, renderer) => {
    workbook.activeWorksheet.setStyle('A1:C1', { bold: true });
    renderer.render();
  }}
/>
