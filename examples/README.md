# Ezygrid examples

Standalone HTML demos of the current version. Build the bundles once:

```sh
npm run examples:build
```

Then open the files directly in a browser (no server needed):

- `basic.html` — workbook model: two sheets, cross-sheet formulas, styles, number formats
- `full.html` — toolbar + formula bar, validation, conditional formatting, structured table, chart, shape, CSV export
- `react.html` — `<Spreadsheet>` from `@ezygrid/react` on React 19
