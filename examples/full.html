Try it yourself

  1. Try entering -1 in C2. The quantity rule rejects values outside 0–1,000.
  2. Edit a status in column E: in stock, low, or out. The color follows the value.
  3. Restock the first two products, hide or show the chart, then export your edited data.

The toolbar and formula bar are renderer options. This example passes them through renderer.

See the setup 
<div id="editor" style="height: 460px"></div>
<script src="/ezygrid/ezygrid.js"></script>
<script>
  Ezygrid.ready.then(() => {
    const editor = new Ezygrid({
      target: '#editor',
      renderer: { toolbar: true, formulaBar: true },
      worksheets: [{ data: [['Item', 'Qty'], ['Widget', 25]] }],
    });
    editor.workbook.activeWorksheet.addValidation({
      range: 'B2:B50', type: 'number', action: 'reject', min: 0, max: 1000,
    });
  }).catch(console.error);
</script>
