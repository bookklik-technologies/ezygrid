Example 04

Create. Reuse. Clean up.

The loader can live in the document head. After readiness, retrieve an editor, rescan without losing edits, or destroy it before removing the host.

Editor lifecycle

Loading the editor...

Try it yourself

  1. Change the first cell, then select Rescan host. You get the same instance and keep your edits.
  2. Select Destroy editor. The grid is removed and the host stays in place.
  3. Select Initialize again to create a fresh editor. Previous edits are not restored.

For a dynamically added marked div, call Ezygrid.initAll(host). Ordinary divs need explicit cleanup.

See the setup 
<head>
  <script src="/ezygrid/ezygrid.js"></script>
</head>
<body>
  <div id="editor" data-ezg-editor style="height: 460px"></div>
  <script>
    Ezygrid.ready.then(() => {
      const editor = Ezygrid.getInstance('#editor');
      Ezygrid.initAll(editor.target); // Reuses the same instance.
      // When removing or replacing the editor:
      // editor.destroy();
    }).catch(console.error);
  </script>
</body>
